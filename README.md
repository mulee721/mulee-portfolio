
# Mulee | Full-Stack Developer Portfolio

A modern, responsive developer portfolio built with React, TypeScript, and Tailwind CSS. Showcasing my technical skills, projects, education, and development journey.

## Features

- Responsive design for desktop, tablet, and mobile
- Professional introduction and About section
- Technical skills showcase
- Projects portfolio with project details
- Education and experience
- Contact section
- Light and dark themes
- Multilingual support

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mulee721/mulee-portfolio.git
```

### 2. Open the project

```bash
cd mulee-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```
