# Mulee — Developer Portfolio

A modern, responsive developer portfolio built with **React, TypeScript, and Tailwind CSS**.

## Features
- Responsive design for desktop, tablet, and mobile
- Professional introduction and About section
- Technical skills showcase
- Projects portfolio
- Education and experience
- Contact section

## Tech Stack
- React
- TypeScript
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```
